# Security Policy

## Supported versions

Security fixes are released for the latest version of Just Wanna Be a User. Please update to the latest release before reporting an issue.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |

## Reporting a vulnerability

Please report security issues privately. Don't use the public WordPress.org support forum or a public issue tracker for them.

- **Security contact:** open a private report at <https://github.com/vPereira04/just-wanna-be-a-user/security/advisories/new> (GitHub private vulnerability reporting). Only the maintainer can see it.

Please include:

- the plugin version, plus your WordPress and PHP versions;
- the steps to reproduce the issue, or a proof of concept;
- what an attacker could do with it.

## What happens next

- You get a first response within 5 business days, confirming we received your report.
- We look into it and keep you posted on progress in the same advisory.
- Once a fix ships, its changelog entry starts with **Security:** so site owners know to update. Fixed issues are published as GitHub security advisories.

Please don't disclose the issue publicly until a fix is available. We're happy to credit you in the changelog if you'd like.
